# 나를 소개하는 포트폴리오

순수 HTML, CSS, JavaScript로 만든 반응형 개인 포트폴리오입니다. 시맨틱한 페이지 구조, 모바일 내비게이션, 다크 모드, 폼 입력 검증, GitHub API 프로젝트 목록 등 웹 프론트엔드의 기초 동작을 구현합니다.

## 실행하기

1. 이 저장소를 내려받아 VS Code에서 엽니다.
2. VS Code 확장에서 **Live Server**를 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.

빌드 도구나 외부 프론트엔드 라이브러리는 사용하지 않습니다. 파일을 직접 브라우저에서 여는 것보다 Live Server 같은 로컬 웹 서버를 사용하면 `fetch`와 경로를 안정적으로 확인할 수 있습니다.

## 파일 구성

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── profile.svg
├── README.md
└── tect.md
```

## 내 정보로 수정하기

- `js/script.js`의 `GITHUB_USERNAME`을 본인의 GitHub 아이디로 바꾸세요. 아이디만 입력하고 토큰이나 비밀번호는 넣지 않습니다.
- `index.html`에서 이름, 소개, 관심 분야, 기술 목록과 저작권 표시를 본인 정보로 수정하세요.
- 실제 프로필 사진을 사용하려면 이미지를 `images/`에 추가하고 `<img>`의 `src`, 설명에 맞는 `alt`를 수정하세요.
- 문의 폼은 브라우저에서 입력을 검증하고 성공 안내를 보여주는 학습용 폼입니다. 서버나 이메일 전송 서비스에 연결되어 있지 않으므로 실제 메시지는 전송되지 않습니다.

## 구현 기능

- 모바일 내비게이션과 앵커 부드러운 스크롤
- 스크롤 60px 이후 헤더 스타일 변경, 300px 이후 맨 위 버튼 표시
- 다크 모드 및 `localStorage`를 이용한 테마 유지
- Intersection Observer를 이용한 콘텐츠 등장 효과
- 이름·이메일·메시지 필수값 검사와 이메일 형식 검사
- GitHub 공개 저장소 API 연동 및 로딩·성공·오류·빈 상태 표시
- 768px, 1024px 브레이크포인트를 사용하는 모바일 퍼스트 반응형 레이아웃

구현 이유와 각 코드의 동작 원리는 [tect.md](./tect.md)에 학습용으로 설명되어 있습니다.

## GitHub Pages 배포

**GitHub 저장소 URL:** 아직 저장소에 올리기 전입니다. GitHub에 업로드한 뒤 실제 저장소 주소를 적으세요.

1. 저장소 최상위에 `index.html`이 있는지 확인하고 GitHub에 푸시합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Deploy from a branch**를 선택합니다.
4. 기본 브랜치(예: `main`)와 폴더(`/ (root)`)를 선택하고 저장합니다.
5. Pages 설정에 표시되는 URL을 열어 페이지, API, 모바일 메뉴, 폼, 테마를 확인합니다.
6. 아래 배포 URL을 실제 주소로 바꾸고 스크린샷을 추가합니다.

**배포 URL:** 아직 배포 전입니다. 배포 후 `https://<아이디>.github.io/<저장소명>/` 형식의 실제 주소를 적으세요.

